교토 체험 하나 고르기

관광 사이에 하나만 넣는 정도가 가장 부담이 적어요.

👘 기모노 · 유카타

교토 전통거리 분위기를 가장 제대로 느끼고 사진을 많이 남길 수 있는 선택.

  • 의상 선택 → 착용 → 헤어 옵션 → 거리 산책 → 반납
  • 기요미즈데라·산넨자카와 특히 잘 어울림
  • 전통거리를 천천히 걸으며 사진 남기기 좋음
⏱ 약 3~5시간

🍵 다도 · 말차

말차를 마시는 법과 기본 예절을 배우고 직접 차를 내보는 전통문화 체험.

  • 설명 → 시연 → 직접 말차 만들기 → 화과자와 함께 시음
  • 관광 사이에 짧게 넣기 좋은 체험
  • 일본 전통문화를 직접 경험하는 느낌이 뚜렷함
⏱ 약 45~60분

🍡 화과자 만들기

색색의 앙금으로 계절 모양 화과자를 직접 만들고 완성품을 먹어보는 체험.

  • 설명 → 모양 잡기 → 장식 → 완성 → 말차와 함께 먹기
  • 4명이 각자 만든 결과물을 비교하는 재미
  • 캐주얼하고 참여감이 큰 체험
⏱ 약 60~90분

🍶 사케 양조장 · 시음

교토의 전통 사케 문화를 알아보고 양조 과정과 다양한 사케를 경험하는 코스.

  • 양조장·사케 박물관 관람 → 제조 과정 소개 → 제품 구경·시음
  • 후시미 지역은 교토를 대표하는 사케 양조 지역
  • 관광지와 다른 분위기의 로컬문화 체험
⏱ 약 1~2시간
